La programación es el proceso de crear instrucciones para que una computadora realice determinadas tareas. Para ello se utilizan algoritmos, que son conjuntos de pasos ordenados y claros para solucionar un problema. Las variables permiten almacenar datos que pueden cambiar durante la ejecución de un programa, mientras que los tipos de datos indican qué clase de información se guarda, como texto, números enteros, decimales y valores booleanos (verdadero o falso). Los operadores permiten realizar operaciones, como suma, resta, multiplicación y división. El pseudocódigo sirve para planificar la solución de un problema antes de escribir el código, usando instrucciones sencillas. Por otro lado, un diagrama de flujo representa gráficamente los pasos de un algoritmo mediante símbolos como óvalo (inicio/fin), rectángulo (proceso), rombo (decisión) y flechas (dirección del flujo).
